# CSS and Bootstrap Portfolio

# Overview
This repository contains projects created using CSS and Bootstrap during my web development course. These projects demonstrate my understanding of styling, layout design, responsive web development, and modern front-end frameworks.
CSS was used to control the appearance, layout, and visual design of web pages. Bootstrap was used to create responsive, mobile-friendly layouts quickly using its grid system and built-in components

# HTML
- Provides the structure of web pages
- Uses semantic elements such as `<header>`, `<section>`, and `<footer>`

# CSS
- Used to style web pages
- Controls colors, fonts, spacing, layout, and positioning
- Includes features such as:
  - Classes and IDs
  - Flexbox and layout tools
  - Hover effects and transitions
  - Responsive design techniques

# Bootstrap 
Bootstrap is a front-end framework that helps create responsive websites quickly.

Bootstrap features used include:
- Grid system (12-column responsive layout)
- Containers, rows, and columns
- Responsive navigation bars
- Buttons and cards
- Built-in spacing and alignment utilities
- Mobile-first responsive design
